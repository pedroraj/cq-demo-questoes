# cq-demo-questoes

Questões de demonstração do canal-questoes (TCC de Pedro Ribeiro, Ciência da Computação, Unicamp), no formato
do PrairieLearn. Cada questão usa um dos cinco elementos suportados; as que têm `server.py` sorteiam os valores
por aluno.

Gerais:
- `capital`: capital de um estado brasileiro sorteado (`pl-multiple-choice`);
- `primos`: números primos (`pl-checkbox`);
- `velocidade`: velocidade média (`pl-number-input`);
- `soma`: soma de inteiros (`pl-integer-input`);
- `palavra`: uma palavra (`pl-string-input`).

Organização de computadores:
- `arq-binario`: binário sem sinal para decimal (`pl-integer-input`);
- `arq-complemento`: complemento de dois em 8 bits (`pl-integer-input`);
- `arq-hexa`: decimal para hexadecimal (`pl-string-input`);
- `arq-desempenho`: tempo de execução por instruções, CPI e frequência (`pl-number-input`);
- `arq-riscv`: registrador de endereço de retorno no RISC-V (`pl-multiple-choice`);
- `arq-potencias`: potências de dois (`pl-checkbox`).
