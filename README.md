# cq-demo-questoes

Questões de demonstração do canal-questoes (TCC de Pedro Ribeiro, Ciência da Computação, Unicamp), no formato do PrairieLearn.
Uma questão por elemento suportado: `pl-multiple-choice` (capital), `pl-checkbox` (primos),
`pl-number-input` (velocidade, com parâmetros sorteados), `pl-integer-input` (soma, com parâmetros sorteados) e
`pl-string-input` (palavra).
